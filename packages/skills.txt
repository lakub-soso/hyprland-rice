# Agent skills from skills.sh, one owner/repo@skill per line.
# Installed globally (~/.agents/skills, linked into Claude Code + Codex) by
#   ./install.sh ai        (uses `npx skills add`, needs node from ./install.sh dev)
# Find more: npx skills find <query>
#
# Skills are instructions for agents that can run shell commands, so each repo
# is pinned to a commit ("pin owner/repo <commit>"): installs are reproducible
# and a later push to the repo can't change what gets installed. To update a
# repo: review what changed (https://github.com/<owner>/<repo>/compare/<old>...<new>),
# then replace the commit with the new one (git ls-remote https://github.com/<owner>/<repo> HEAD).
# Unpinned repos still install (latest commit), with a warning.
# Note: `npx skills update -g -y` ignores these pins and moves to latest.
